Wrap 2026 — Badge reference

Two badge systems. A = badges the Wrap computes. B = learning badges the gamification service already awards (Wrap only reads). C = the curation rules that guarantee every student type — top, middle, and low-activity — earns at least one badge and nobody sees an empty shelf. Each metric is a ladder with a low starter rung, so a barely-active student still lands on a badge — plus two universal badges every eligible student can reach. ALL universal · LOW low-activity · MID middle · TOP high achiever.

C · Every student earns something — curation rules

The badge shelf must only ever add pride, never highlight absence. These rules make that true for all ~20–30k students.

  1. Everyone earns ≥ 1. The starter rungs clear at ~1, so any student who studied even one day gets যাত্রা শুরু. A Fresh-Start student is never badge-less.
  2. Show the top rung per ladder, 3–4 badges max. Don't dump the whole list — one badge per metric (the highest cleared), ordered achievement-first.
  3. Never show absence. No "0 badges", no empty shelf, no greyed / locked "not earned" badges shown to low performers.
  4. Loyalty is unconditional. Returning students always get শিখোর সাথী, independent of 2026 activity.
  5. If still zero (edge case), fall back to the universal participation badge — the shelf is never blank.
